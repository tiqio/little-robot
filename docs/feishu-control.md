# 飞书控制台：压缩 / 清理 / 停止（ch39–ch41）

> 手机上的痛点：任务跑没跑完看不出来，想打断只能干等，想清上下文只能靠重启。
> 这三件事做成"点一下就生效"的按钮，并且**都有文本命令兜底**——
> 按钮依赖飞书后台的卡片回调配置，文本命令不依赖任何配置。

对应代码：`internal/feishu/control.go`、`internal/feishu/bot.go`、`internal/engine/loop.go`（`CompactSession`）。

---

## 1. 三个动作分别做什么

| 动作 | 按钮 | 文本命令 | 干了什么 |
|---|---|---|---|
| 压缩 | 🧹 压缩上下文 | `压缩` | 立刻压缩历史（不等阈值）：保护区收到最近 8 条，老的工具输出折叠成占位符。**消息条数不变**，只是内容变短，模型还记得"这儿有东西"。压缩后自动落盘 |
| 清理 | 🗑 清理上下文 | `清理` | 清空内存历史 **+ 删除磁盘上的 `sessions/<chat_id>.json`**（只清内存的话，重启会"复活"旧上下文），等于重新开始 |
| 停止 | ⏹ 停止任务 | `停止` | 取消这个群正在跑的那次 Run（`context.CancelFunc`），当前工具步骤结束即退出 |

**没东西可操作时只提示，不报错**（就是需求里说的"没有跑就直接不管然后提示"）：

| 情况 | 回执 |
|---|---|
| 点「停止」但空闲 | `当前没有正在跑的任务` |
| 点「压缩」但没历史 | `这个群还没有上下文，不用压缩` |
| 点「压缩」但已经压不动 | `已经很紧凑了（N 字符），压不动` |
| 点「清理」但本来就是空 | `上下文本来就是空的` |

## 2. 怎么调出按钮

- **每轮任务结束后自动跟一张**：`✅ 完成（…）` 或 `⚠️ 任务中断（…）` 之后就是控制台卡片
- 或者随时发 **`面板`** / `控制台` / `按钮` / `菜单`，秒回卡片（不走模型）

## 3. 文本命令（卡片回调没开通也能用）

手机打字费劲，所以命令都很短，中英文都行：

| 命令 | 等价 |
|---|---|
| `压缩` · `压缩上下文` · `压一下` · `/compact` | 压缩 |
| `清理` · `清理上下文` · `清空` · `/clear` | 清理 |
| `停止` · `停` · `停下` · `中断` · `/stop` | 停止 |
| `面板` · `控制台` · `菜单` · `/menu` | 调出卡片 |
| `自检` · `体检` · `状态` · `/doctor` · `/status` | 体检报告 |

两个实现细节：

1. **命令在抢群锁之前处理**——所以任务正在跑时发 `停止` 才来得及生效；
   如果走"排队等锁"的路径，任务跑完才会轮到你这条消息，停止就变成马后炮了。
2. **压缩/清理在任务跑着时会拒绝**，并提示先停止：中途改历史会让正在跑的 Run 上下文错乱。

## 4. 自检（排查按钮为什么不灵）

发 `自检`，回一份体检报告：

```
🩺 自检
卡片回调：❌ 一次都没收到过
  → 点按钮没反应的话，去飞书后台「事件与回调 → 回调配置」
     选「长连接」并添加 card.action.trigger
  → 在此之前用文本命令：压缩 / 清理 / 停止
上下文：48 条 / 约 9683 字符
当前任务：空闲
单次超时：20m0s（RUN_TIMEOUT_MIN 可调）
```

`卡片回调：✅ 已收到 N 次` = 后台配置生效；`❌` = 去按
[feishu-setup.md 1.5.1](./feishu-setup.md#151-回调配置要卡片按钮就必须配ch39-ch41) 配一遍。

## 5. 会话与超时

- **每个群聊是一个会话**：`chat_id` → `workspace/chats/<群名>/.claw/sessions/<chat_id>.json`，
  记忆按群隔离；同群串行执行（一个在跑时，新消息会收到"⏳ 上一个任务还在跑"）
- **单次任务超时**：默认 20 分钟，`.env` 里 `RUN_TIMEOUT_MIN` 可调。
  原来写死 10 分钟，本地 27B 跑"抓本子 + 多轮工具 + 合成 PDF"会撞线，
  用户看到的就是 `⚠️ 任务中断：context deadline exceeded`

## 6. 实现要点（改代码时看这里）

```go
// 卡片回调与文本命令共用同一份逻辑，避免"点了没反应但打字有效"
func (b *Bot) perform(cmd, chatID string) (msg string, ok bool)

// 外壳不碰 compactor：引擎暴露"压缩这个会话"这一个动作
func (e *AgentEngine) CompactSession(s *session.Session) (before, after int)
```

- `Bot.cancelers map[chatID]context.CancelFunc`：每群最多一个在跑的 Run，
  Run 结束时 `defer` 注销；`performStop` 取到就 `cancel()`
- `Bot.cardCallbacks atomic.Int64`：回调计数，只用于自检
- 卡片是 **card v1 JSON**（`config/header/elements`），按钮的 `value` 会原样回到
  `callback.CardActionTriggerEvent.Event.Action.Value`
- Toast 只对点击者可见，所以压缩/清理这类**共享状态变更**额外在群里发一条
